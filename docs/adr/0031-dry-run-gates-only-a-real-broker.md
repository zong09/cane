# ADR 31 · `dry_run` กั้นเฉพาะ broker ที่ส่งคำสั่งจริงได้ — paper จำลองเสมอ

**สถานะ:** accepted · **ปรับถ้อยคำของ [spec/06 §dry_run](../spec/06-risk-and-execution.md)**

profile `paper` ถูกบังคับ `dry_run = true` ตายตัว (validator และ CHECK ของ DB) และขั้น 13 ของ
[spec/08 §สิบสี่ขั้นของหนึ่งรอบ](../spec/08-runtime-pipeline.md) เขียนว่า "ขา 2: เปิดสถานะ **หรือข้ามถ้า dry_run**" ·
สองข้อนี้ต่างถูกทั้งคู่ แต่รวมกันแล้ว **paper ไม่มีวันเปิดไม้เลย** — replay ย้อนหลังของใบ 12 จะได้บันทึกครบทุกแท่ง
โดยไม่มีเทรด ไม่มี P&L ไม่มี flip และไม่มีอะไรทดสอบ `PaperBroker` เลย ซึ่งขัดกับเกณฑ์ "จำนวนเทรดสมเหตุสมผล"

เจตนาของการบังคับ paper คือ *"ต้องไม่มีทางส่งคำสั่งจริงได้เลย"* (ข้อความใน `config/settings.py`) — ซึ่งจริงอยู่แล้วโดยโครงสร้าง
เพราะ `PaperBroker` ไม่มีทางออกไปหา exchange · ธง `dry_run` ไม่ได้เป็นสิ่งที่กัน paper

## ตัดสิน

ขั้น 13 ข้ามขาเปิดเมื่อ **`dry_run` และ `broker.kind == "ccxt"`** · paper ส่งคำสั่งให้ `PaperBroker` จำลองเสมอ

- config ของ paper ยังเป็น `dry_run = true` และยังบังคับเหมือนเดิม — ไม่มีอะไรใน validator หรือ DB เปลี่ยน
- `decisions._check_dry_run` (ตัวตรวจว่า "แท่ง dry_run ห้ามมีออเดอร์เปิดที่ `sent = True`") ยกเว้น `profile = 'paper'`
  · ตัวตรวจเดิมยังดังเมื่อ live ที่ `dry_run = true` มีออเดอร์หลุดออกไป ซึ่งคือสิ่งที่มันมีไว้จับ
- `DecisionRecord.dry_run` ของ paper ยังบันทึกค่าของ config ตามจริง (`true`) — ไม่แกล้งเป็น `false`

## ทำไมไม่ทำทางอื่น

- **แก้ให้ paper ตั้ง `dry_run = false` ได้** — เปิดช่องให้ config ที่ตั้งผิดดูเหมือนส่งจริง และทำลายการ
  บังคับที่คนอ่านคอนโซลพึ่งอยู่ ("paper = ไม่มีทางส่งจริง")
- **ให้ replay ใช้ profile ที่สาม** — [ข้อ 9](0009-paper-and-live-are-profiles.md) ว่า paper กับ live เป็น profile ไม่ใช่โหมด และ
  replay ต้องเป็นโค้ดเส้นเดียวกับ live · profile ที่สามคือ runner ตัวที่สองในอีกชื่อหนึ่ง
- **ยอมให้ replay ไม่มีเทรด** — ผ่านเกณฑ์ "เขียนบันทึกทุกแท่ง" แต่ไม่พิสูจน์ flip, stop, fee, PaperBroker
  ซึ่งเป็นของที่ใบ 08–11 สร้างไว้แล้วไม่เคยถูกรันด้วยของจริง

## ผลตามมา

- ค่าที่ live ยังเป็นตามเดิมทุกอย่าง: `dry_run` เป็นค่าตั้งต้น `true` และกั้นขาเปิดที่ `CcxtBroker`
- เงื่อนไขนี้อยู่ที่ขั้น 13 ที่เดียว (`engine/pipeline.py`) — ไม่แตกไปเป็นเช็กที่ `PaperBroker`
