# ADR 6 · LLM ล้มเหลว → ลงไม้ `base_pct`

**สถานะ:** accepted

สัญญาณ buy เป็น deterministic และไม่พึ่ง LLM กรณีนี้จึงตรงกับ "สัญญาณพื้นฐานที่ไม่มีปัจจัยสนับสนุน" ในเอกสารต้นทางพอดี

ทางเลือกที่ปฏิเสธ: ข้ามสัญญาณไปเลย — จะทำให้ความเสถียรของผู้ให้บริการ LLM กลายเป็นตัวแปรของกลยุทธ์

**ผลตามมา:** ต้องติดธงใน DecisionRecord ให้แยกออกจากกรณีที่ LLM ตัดสินจริงว่าไม่มีปัจจัย
