# ADR 16 · คงการยิงอัตโนมัติเต็มรูปแบบ ไม่มี human gate ต่อไม้

**สถานะ:** accepted

design handoff เคยมีสิทธิ์ `กดยืนยันเข้าไม้` ในตาราง permission — ตัดออก เพราะขัดกับ #7 โดยตรง การใส่คนกลับเข้ามาตรงจุดเข้าไม้คือการเปิดช่องให้อคติกลับเข้ามาพอดีตรงที่ระบบตั้งใจตัดออก

คนกดได้สองอย่าง: **เลือกเส้นทาง cold start** และ **ปิดไม้ฉุกเฉิน** ทั้งคู่เป็นการลดความเสี่ยงหรือเลือกไม่ทำ ไม่มีปุ่มไหนที่คนกดแล้วเปิดไม้ใหม่ได้

**2026-09-01:** design handoff ชุด v3 ยังมีสิทธิ์ `กดยืนยันเข้าไม้ / ปิดไม้` อยู่ในตาราง permission
(ทั้งไฟล์ light, dark v3 และ `appendix/01`) เจ้าของระบบยืนยันมติเดิม — **สิทธิ์นี้ถูกตัดออก**
เป็น errata ที่ต้องแจ้งกลับไปที่ design ไม่ใช่การกลับมติ
