# ADR 1 · ใช้ Python

**สถานะ:** accepted

ccxt และ pandas เป็นมาตรฐานของงาน TA และการ port Pine Script มาเป็น pandas ตรงไปตรงมาที่สุด

**ผลตามมา:** ต้องระวังเรื่องความเร็วเมื่อ symbol เยอะขึ้น แต่ระบบนี้ตัดสินใจวันละครั้งต่อ symbol จึงไม่ใช่ข้อจำกัดจริง
