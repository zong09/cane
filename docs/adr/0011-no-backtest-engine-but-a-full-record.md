# ADR 11 · เฟสแรกยังไม่มี backtest engine แต่บังคับบันทึกให้ครบ

**สถานะ:** accepted — เจตนาคงเดิม แต่สื่อกลางเปลี่ยนจาก JSONL เป็นตารางโดย [ADR 22](0022-everything-in-postgresql.md)

เจ้าของระบบเลือกทำ live signal bot ก่อน

**ผลตามมา:** ยังไม่มีหลักฐานเชิงตัวเลขว่าระบบมี edge จริงก่อนเริ่มใช้เงินจริง — เป็นความเสี่ยงที่รับทราบแล้ว การบังคับเขียน DecisionRecord ทุกแท่งทำให้ replay ย้อนหลังได้ในภายหลังโดยไม่ต้องรื้อระบบ
