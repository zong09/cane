# ADR 19 · ของที่ค้างจาก `flip_aborted` ระบบไม่ปิดเอง คนปิดด้วยมือ

**สถานะ:** accepted

เมื่อขาปิดของ flip ทำงานไม่ครบ ส่วนที่เหลือยังเปิดค้างอยู่ที่ exchange โดยที่เส้นทาง
ออกตามปกติของมัน (สัญญาณฝั่งตรงข้าม) เพิ่งใช้ไปแล้วในแท่งนั้นและจะไม่เกิดซ้ำ
จนกว่าเทรนด์จะกลับอีกรอบ

เจ้าของระบบเลือก **คงพฤติกรรมนี้ไว้** และให้คนปิดเองผ่านสิทธิ์ "ปิดไม้ฉุกเฉิน"
ที่มีอยู่แล้วใน #16

ทางเลือกที่ปฏิเสธ:

1. **รีไทร์การปิดทุกแท่งจนกว่าจะหมด** — สร้างเส้นทางที่ระบบยิงคำสั่งนอกจังหวะสัญญาณ
   ซึ่งขัดกับหลักที่ว่าทุกการกระทำผูกกับแท่งที่ปิดแล้วและสัญญาณที่ตรวจสอบได้
2. **วาง stop ให้ส่วนที่เหลือ** — ขยาย stop จากเรื่องเฉพาะของ cold start ทางที่ 2
   (#17) ไปเป็นกลไกทั่วไป ทั้งที่เส้นทางปกติไม่มี stop โดยเจตนา

ทั้งสองทางเพิ่มโหมดการทำงานที่เกิดยากและทดสอบยาก บนเส้นทางที่ตัวมันเองก็เกิดยากอยู่แล้ว

**ผลตามมา — ข้อแลกเปลี่ยนที่ต้องจ่าย:** ไม้ที่ค้างเป็นไม้ที่มี leverage และไม่มี stop
อยู่จนกว่าคนจะเห็นและปิด ทางนี้จะใช้ได้จริงก็ต่อเมื่อระบบทำให้มัน **มองไม่พลาด**
จึงบังคับสามอย่าง: บันทึก `residual_qty` ตอนเกิด · เจอสถานะที่ระบบไม่ได้ตั้งใจถือเมื่อไหร่
ให้เขียน `unmanaged` **ซ้ำทุกแท่ง** ไม่ใช่ครั้งเดียว · คอนโซลแสดงเป็นสิ่งที่ต้องคนจัดการ
แยกจากไม้ปกติ ถ้าสามข้อนี้ไม่ครบ การตัดสินใจนี้จะกลายเป็นการเงียบใส่ความเสี่ยง
