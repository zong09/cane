# 00 · ภาพรวมระบบ (cane)

## ระบบนี้คืออะไร

บอทเทรดคริปโตที่ทำงานตามระบบ CDC Action Zone ของลุงโฉลก สัมพันธารักษ์ อ่านราคาจาก exchange ตรวจสัญญาณเปลี่ยนแนวโน้ม ประเมินปัจจัยสนับสนุน แปลงเป็นขนาดหน้าตัก แล้วส่งคำสั่งซื้อขายเอง

ตลาดคือ **USDT-M perpetual futures** มี leverage และ **เทรดสองฝั่ง** — เขียวแรกเปิด long แดงแรกปิด long แล้วเปิด short ในแท่งเดียว

## ปัญหาที่ตั้งใจแก้

เอกสารต้นทางระบุจุดตายของนักเทรดไว้สองข้อ:

1. **อคติ** — เห็นราคาวิ่งแล้วดื้อไล่ซื้อ, ขายหมูเพราะกลัว, อ่านข่าวแล้วเปลี่ยนใจ
2. **ขนาดไม้** — "หัวใจไม่ใช่การทายถูก แต่คือการบริหารหน้าตัก"

ระบบอัตโนมัติตัดข้อแรกออกโดยธรรมชาติ (เครื่องไม่มีอารมณ์) และบังคับข้อที่สองให้เป็นสูตรที่ตรวจสอบได้แทนความรู้สึก

## ขอบเขต

### อยู่ในระบบ
- สัญญาณ CDC Action Zone บนกราฟรายวัน (§2 ของเอกสารต้นทาง) ใช้กับทั้งสองฝั่ง
- ตารางขนาดหน้าตักตามปัจจัยสนับสนุน (§3) — bucket และเพดานแยกฝั่ง
- กฎไม้เรียว และทางเลือกเมื่อตกรถ (§4) บังคับทั้งสองฝั่งเท่ากัน
- Reward-to-Risk อย่างน้อย 2:1 ในเส้นทาง late entry
- ชั้นความเสี่ยงเฉพาะของ perp — เพดาน leverage และระยะขั้นต่ำถึงราคา liquidation

### ตั้งใจไม่เอาเข้าระบบ
- **เป้าราคารายสินทรัพย์ (§6 ของเอกสารต้นทาง)** — "BTC $100,000", "ทอง $5,400–5,600" เป็นบทวิเคราะห์ ณ ช่วงเวลาหนึ่ง ไม่ใช่กฎของระบบ ถ้า hardcode ไว้ มันจะกลายเป็นระเบิดเวลาที่ยังตัดสินใจให้เราอยู่หลังจากสมมติฐานเดิมหมดอายุไปแล้ว
- **จิตวิทยาและการสร้างบารมี (§5)** — เป็นวินัยของคนเทรด ไม่ใช่ logic ที่เครื่องรันได้ ทิ้งไว้ให้คนอ่านเอกสารต้นทางเอง
- **การทำนายจุดสูงสุด/ต่ำสุด** — เอกสารย้ำเองว่า "ระบบไม่เคยหลอกเรา แต่บอกเราช้ากว่าเหตุการณ์เสมอ" ระบบนี้เป็น lagging indicator โดยเจตนา

## ลักษณะเด่นที่ต้องรักษาไว้

| หลักการ | สิ่งที่แปลว่าในทางวิศวกรรม |
| --- | --- |
| ระบบตอบเหมือนเดิมเสมอบนข้อมูลชุดเดิม | คำตัดสินของ LLM ถูก cache ต่อแท่ง ตัดสินครั้งเดียวจบ |
| ระบบตามหลังเหตุการณ์ ไม่ล่วงหน้า | ตัดสินใจบนแท่งที่ปิดแล้วเท่านั้น ไม่มีการมองอนาคต |
| ขนาดไม้มาจากสูตร ไม่ใช่ความรู้สึก | `base_pct` เป็นค่าคงที่ ไม่ผูกกับ confidence ของ LLM |
| อยู่รอดสำคัญกว่ากำไร | ทุก risk limit fail-closed — ตั้งไม่ครบ = ไม่เทรด |
| หนึ่งฝั่งต่อเหรียญเสมอ | one-way ห้ามถือสวนกัน จุดเดียวที่เข้าใกล้การละเมิดคือ flip จึงต้อง abort เป็นค่าตั้งต้น |
